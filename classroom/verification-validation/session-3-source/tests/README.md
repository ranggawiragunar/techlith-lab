# Student-owned tests

Write your own Vitest files in this directory. The starter deliberately contains no requirement-answer suite. Suggested files are `inventoryRules.test.ts`, `quantityRules.test.ts`, `inventoryState.test.ts`, and `usageBased.test.ts`.

Start with one requirement or model transition, state the expected behavior from the canonical requirement, then record the input and evidence. Use controlled mutants as separate fault-based exercise variants; do not turn this folder into an answer key for another student.
